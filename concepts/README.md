## Честно о «99%»

Гарантировать популярность невозможно: судьбу игры решают исполнение, стиль, первые клипы и удача. Но эти 5 концептов собраны так, чтобы повысить шансы:

1. **Проверенный спрос.** Каждый концепт стоит на жанре, который уже приносит хиты в Steam: вечеринки с физикой, голосовые шоу, кооперативы, игры «найди предателя», кооп-хорроры.
2. **Свой поворот.** У каждого есть механика, которой нет у конкурентов: перетасовка управления, суфлёр с запретом на смех, проклятый, не знающий о себе, рассинхрон реальностей, режиссёр страха среди своих.
3. **Клипы встроены в дизайн.** Везде есть повтор-раскрытие, который сам создаёт момент для нарезки.
4. **Объясняется за 5 секунд.** Логлайн умещается в одну фразу и в первый кадр трейлера.
5. **Проверка до вложений.** В каждом документе есть метрики «играть дальше / переделать» для прототипа на кубиках.

## Что общее для всех пяти (не забыть)

- Лобби Steam с приглашением в один клик, Remote Play Together.
- **Friend Pass**: одна покупка, друг играет бесплатно (или скидка на набор из 4 копий).
- Кнопка «Сохранить клип» с водяным знаком игры: бесплатная реклама.
- Косметика позора для проигравшего.
- Стример-режим: фильтры, задержки, понятный интерфейс для зрителя.
- Локализация сразу на 8–10 языков: дёшево, а аудитория игр с друзьями очень международная (Бразилия, Китай, СНГ, Европа).
- Цена $5–8: игру с друзьями покупают «на компанию».

## Путь к релизу (одинаковый для любого концепта)

1. **Прототип на кубиках** (4–10 недель) и плейтесты с 5 реальными компаниями.
2. Если метрики пройдены: **страница в Steam** сразу, чтобы копить список желаемого. Неформальный ориентир — десятки тысяч добавлений к моменту релиза.
3. **TikTok, Shorts и Reels** с настоящими моментами из плейтестов, 3–5 роликов в неделю.
4. **Демо на Steam Next Fest**, раздача ключей небольшим стримерам.
5. Релиз в ранний доступ, бесплатные обновления каждые 4–6 недель (новые режимы и карты).

## С чего начать

- **Первая игра, минимальные вложения:** «Суфлёр» или «Кто криворукий?».
- **Максимум вирусности:** «Чужие руки» или «Спящий агент».
- **Самый денежный жанр:** «Тут никого нет», но для команды с опытом в звуке и атмосфере.

Если хватает сил на прототипы, разумная стратегия — сделать 2–3 прототипа по 2–3 недели и продолжать тот, на котором друзья смеялись громче всего.
